## 📌 Objetivo

Este repositório tem como objetivo armazenar atividades práticas, pesquisas e scripts desenvolvidos durante a disciplina de DevOps, utilizando principalmente **Bash Script** e ferramentas Linux para automação e administração de sistemas.

As atividades abordam conceitos fundamentais de infraestrutura, monitoramento e operações, incluindo:

* Manipulação e gerenciamento de arquivos
* Análise e monitoramento de logs
* Automação de tarefas administrativas
* Uso de comandos essenciais Linux
* Práticas de redes e infraestrutura
* Estudos e pesquisas sobre Docker
* Controle de versões com Git e GitHub
